## 三、验收清单（每项都要能演示）
1. 秒传：同一文件二次上传，接口直接返回，无网络传输（DevTools 可见）
2. 断点续传：传 60% 时断网/刷新，重新上传只补缺失分片（看服务端日志分片序号）
3. 分布式锁：并发调用 merge 两次，只有一次成功（日志可见锁等待/拒绝）
4. 异步化：`/api/bench/apply-async` 对照接口单请求 ~21ms、50 并发 P99 < 600ms（已实测 596ms；该接口刻意剥离限流/幂等/分布式锁，只隔离「要不要等外部调用」这一变量），简历解析状态从"解析中"→"已完成"
5. 限流：超限返回 429（`GlobalExceptionHandler` 把业务码 429 映射成 `HttpStatus.TOO_MANY_REQUESTS`）并在响应体里带业务提示；**`Retry-After` 响应头未实现，列为待办**；Redis 停掉后降级仍可用
6. 重试：mock 三方 30% 失败，最终成功率 99%+；死信看板能一键重放
7. 幂等：同一条 MQ 消息重投 3 次，业务数据只变一次
8. AI：问"我投的 XX 公司到哪了"能返回真实库里的状态；追问第二轮能理解上下文

## 五、常见坑
- RocketMQ 5 与 SpringBoot 3 需用 rocketmq-spring-boot-starter 2.3.0+，注意 broker 地址配置为宿主机 IP（Docker 内网地址浏览器/本机连不上）
- ComposeObject 要求除最后一片外每个分片对象 >= 5MB，小于会报 EntityTooSmall；分片对象合并后要及时删除，否则存储翻倍
- Redisson tryLock 传 leaseTime = -1 才启用看门狗；传具体时间则不会续期
- LangChain4j 0.35 的注解包是 dev.langchain4j.agent.tool.Tool / P，不同版本包路径有变化
- Vue 大文件 MD5 一定放 Web Worker，否则页面卡死
- 令牌桶的 rate 是"每秒补充令牌数"，capacity 是桶容量；capacity = rate 时即严格 QPS 上限
